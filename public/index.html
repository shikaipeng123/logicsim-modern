使用说明

这个工具做什么

它把一个命题逻辑表达式自动综合成一张由 SEL（2 选 1 选择器， 也就是一路选择端 + 两路数据输入的多路复用器）搭成的电路图，用于在逻辑电路沙盒里照着搭建。 同时给出真值表，并把电路导出成 JSON / SVG / PNG。

三步用法

  1. 在左侧输入逻辑表达式。默认是中缀写法，例如 (a ∧ b) → fe； 也可以切到逆波兰写法，例如 a b . fe >。
  2. 点「解析并出图」，画布上会出现选择器电路，右侧出现真值表和可编辑的图模型 JSON。
  3. 需要带走结果时，用画布工具条导出 SVG / PNG，或用「下载 JSON」保存图模型。

逻辑记号

  • 非 ¬ ! ~ not；与 ∧ & · and；或 ∨ | + or
  • 异或 ⊕ ^ xor；与非 ↑ nand；或非 ↓ nor
  • 推出 → -> implies；等价 ↔ <-> ≡ xnor
  • 常量 0 1 ⊥ ⊤；括号 ( )
  • 量词：∀(a, b, c) 表示对列举出来的每一项都成立（合取折叠，等价 a ∧ b ∧ c）；∃(a, b, c) 表示至少有一项成立（析取折叠）。 这里支持的是有限域量词：把量词后面的取值范围直接写出来。

画布操作

  • 空白处按住拖动 = 平移；滚轮 = 以光标为中心缩放；Alt + 0 = 适应视图。
  • 鼠标移到元件上会浮出「删除」按钮和虚线外框，可以直接改电路，再点「图形转文本」写回 JSON。
  • 右下角小地图可以拖动，用来快速定位；右边界可拖拽调整面板宽度。

图模型的语义

导出的 JSON 里有两类数组：

  • nodeArray：元件。类型有 0（常量零）、1（常量一）、 Import（变量输入）、Export（输出）、SEL（选择器）。
  • linkArray：连线。from/frompid 是起点元件与端口， to/topid 是终点元件与端口。SEL 的输入端口为 SI（选择端）、0、1，输出端口为 N。

和 2021 原版的差异

解析与建模内核沿用原版算法（已用真值表做等价性验证），界面、输入方式、真值表、 导出和本地持久化是新加的；同时修掉了原版几个问题，详见项目 README。
