# LogicSim 2.0 · 逻辑电路图生成器

把一个**命题逻辑表达式**自动综合成由 **SEL**（2 选 1 选择器 / 多路复用器）搭成的电路图，
附带真值表，并可导出成 JSON / SVG / PNG。

本项目是对 2021 年的旧项目 [`kuangdash/logicsim`](https://gitlab.com/kuangdash/logicsim)
（在线地址：<https://kuangdash.gitlab.io/logicsim>）的一次现代化改造：
**解析与建模内核沿用原算法并用基准夹具锁住语义，界面、输入方式与功能做了重做，同时修掉了原版的若干缺陷。**

## 它解决什么问题

原项目是一个「逻辑表达式 → 电路图」的转换器。它的思路是：

1. 把逆波兰（后缀）形式的逻辑表达式解析成一棵**条件选择树**：
   `{ S: 条件, "0": 条件为假时的取值, "1": 条件为真时的取值 }`
2. 把条件选择树规约成一份按变量组织的判定表示，顺带做常量折叠
   （例如 `a ∨ ¬a` 会直接化简成常量 1）
3. 把判定表示编译成由常量、变量输入、输出和 **2 选 1 选择器**组成的连线图

一棵条件选择树恰好对应一个 2 选 1 选择器（S 接选择端，两个分支接两路数据输入），
所以「把表达式编译成选择器电路」本质上就是把表达式规约成条件选择树、再把树画出来。
生成的结果可以直接照着在逻辑电路沙盒里搭。

## 功能

**解析与生成**

- 逆波兰（后缀）输入：原版 5 个运算符 100% 保留，另加异或与单词形式运算符
- 中缀输入：`∧ ∨ ¬ → ↔ ⊕ ↑ ↓` 等符号、`and or not xor nand nor implies xnor` 等单词、
  圆括号、常量 `0 1 ⊥ ⊤`，带完整优先级与结合性
- **量词**：`∀(a, b, c)` 合取折叠、`∃(a, b, c)` 析取折叠（有限域量词）
- 常量折叠：恒真/恒假式会被化简到只剩常量节点
- 中文错误提示，带出错位置

**结果呈现**

- 真值表：变量列 + 结果列，标出最小项 Σm(...)，并判定恒真式 / 矛盾式 / 可满足式
- 统计卡：变量数、节点数、连线数、结果为 1 的行数
- 可编辑的图模型 JSON：画布与文本双向同步

**画布**

- 自动布局（dagre，从左到右）
- 滚轮以光标为中心缩放（10% – 800%）、拖拽平移、一键适应视图
- 小地图：显示全局缩略图与当前可视区域，可拖动定位
- 鼠标悬停显示删除按钮，可直接改电路再写回 JSON
- 点选元件查看/修改名称与备注

**导出与持久化**

- 导出 SVG（自包含，元件图标已内联为 data URI）
- 导出 PNG（2 倍分辨率）
- 下载 / 载入图模型 JSON
- 深浅色主题切换
- 自动把输入、图模型、主题记到 localStorage，刷新不丢

## 输入语法

界面上可切换「中缀」和「逆波兰」两种输入模式。

### 中缀模式（默认）

| 运算符 | 可写形式 | 优先级 |
| --- | --- | --- |
| 非 | `¬` `!` `~` `not` | 6（最高） |
| 与 | `∧` `&` `·` `&&` `and` | 5 |
| 与非 | `↑` `nand` | 5 |
| 或 | `∨` `\|` `+` `\|\|` `or` | 4 |
| 或非 | `↓` `nor` | 4 |
| 异或 | `⊕` `^` `xor` | 3 |
| 推出 | `→` `->` `⇒` `implies` | 2（右结合） |
| 等价 | `↔` `<->` `≡` `==` `xnor` | 1（最低） |

- 常量：`0` `1` `⊥` `⊤` `true` `false`
- 括号：`( )`，也接受全角 `（ ）`
- 量词：`∀(a, b, c)`、`∃(a, b, c)`，项之间用逗号或空格分隔
- 变量名：字母、数字、下划线、`$`、汉字都可以（`-` 不可以用，因为 `->` 是推出）

例子：

```text
(a ∧ b) → fe
∀(a, b, c) → ∃(a, b)
(a ↔ b) ∧ (c → d)
¬a ∨ b ∧ c          # 等价于 (¬a) ∨ (b ∧ c)
```

### 逆波兰模式

记号之间用空格分开，运算符写在操作数之后：

| 记号 | 含义 |
| --- | --- |
| `a b .` | a 与 b |
| `a b ,` | a 或 b |
| `a <` | a 的非 |
| `a b >` | a 推出 b |
| `a b =` | a 等价于 b（同或） |
| `a b ^` | a 异或 b |

另外也接受单词形式：`and or not xor nand nor implies xnor`（注意这些词在逆波兰模式下是保留字，不能当变量名）。

```text
a b . fe >
a b . fe ge > =
```

## 快速开始

纯静态站点，没有构建步骤，但第三方库（JointJS 等约 1.3MB）不进源码仓库，需要先拉一次。

**方式一：直接看线上版**

打开 <https://shikaipeng123.github.io/logicsim-modern/> —— 线上版已经把依赖一起发布好了，什么都不用做。

**方式二：本地跑**

```bash
git clone https://github.com/shikaipeng123/logicsim-modern.git
cd logicsim-modern
bash scripts/vendor-deps.sh          # 拉取固定版本的前端依赖到 public/lib
python -m http.server 8080 --directory public
# 然后打开 http://127.0.0.1:8080/
```

`scripts/vendor-deps.sh` 只依赖 `curl`，跑一次即可；已经存在的文件会跳过。
想指定内网镜像时可以用环境变量 `LIBS_BASE` / `JOINTJS_BASE` 覆盖下载地址。

**方式三：直接双击 `public/index.html`**

拉过依赖之后也可以，但用 `file://` 打开时浏览器会拦住读取元件图标的那次 `fetch`，
画布照常显示（退回相对路径），只是导出的 PNG 里会缺元件图标。
想要完整的导出能力请用方式二。

## 图模型格式

`nodeArray` 是元件，`linkArray` 是连线：

```json
{
  "nodeArray": [
    { "key": "0", "type": "0", "name": "Zero" },
    { "key": 1, "type": "1", "name": "One" },
    { "key": 2, "type": "Export", "name": "Out" },
    { "key": "a", "type": "Import", "name": "a" },
    { "key": 3, "type": "SEL" }
  ],
  "linkArray": [
    { "from": "a", "frompid": "OUT", "to": 3, "topid": "SI" },
    { "from": 3, "frompid": "N", "to": 2, "topid": "OUT" }
  ]
}
```

| `type` | 含义 | 端口 |
| --- | --- | --- |
| `0` | 常量零 | 输出 `OUT` |
| `1` | 常量一 | 输出 `OUT` |
| `Import` | 变量输入，`name` 是变量名 | 输出 `OUT` |
| `Export` | 输出 | 输入 `OUT` |
| `SEL` | 2 选 1 选择器 | 输入 `SI`（选择端）、`0`、`1`；输出 `N`、`SO`、`P` |

连线的 `frompid` / `topid` 是端口 id，`from` / `to` 是元件的 `key`。
`key` 既可以是字符串也可以是数字，`SEL` 的自动编号从 3 开始（0/1/2 已被三个固定节点占用）。

`public/latch.json` 是一个手写的例子：用两个选择器交叉反馈搭出的一个锁存器，可以直接拖进「图模型」面板点「文本转图」看效果。

## 相对 2021 原版的改造点

### 界面

| 原版 | 现在 |
| --- | --- |
| 2011 年风格的布局：`w3.css` + 表格 + `float` + 内联样式，按钮是黄/绿/蓝三色块 | 用 CSS 自定义属性做设计令牌的三段式栅格布局：顶栏 / 输入面板 / 画布 / 结果面板 / 状态栏 |
| 只支持浅色 | 深色 / 浅色双主题，画布元件配色也跟着令牌走 |
| 操作提示是右栏里一大段纯文本 | 可搜索的「记号速查」表格 + 原生 `<dialog>` 使用说明 + toast 提示 |
| `alert()` 弹窗报错 | 面板内联提示条 + 状态栏状态点 + toast |
| 没有 `<title>` /描述 / favicon | 补齐 SEO 与社交分享基础信息，新增 SVG favicon |
| 右侧只有一个 JSON 文本框 | 三个标签页：真值表 / 图模型 / 元素 |
| 布局固定宽度 | 窄屏自动折叠成单列 |

### 输入与能力

- 新增**中缀表达式**输入与完整优先级解析（原版只有逆波兰）
- 新增逻辑连接词：**异或**，以及**与非**、**或非**
- 新增**量词** `∀` / `∃`
- 新增真值表与恒真 / 矛盾 / 可满足判定，标出最小项
- 新增 SVG / PNG 导出
- 新增深色主题、localStorage 自动保存、快捷示例、快捷键

### 工程

- 拆成三层：`LogicParser.js`（纯逻辑：解析 + 建模 + 分析）、`ViewGen.js`（纯数据：判定表示 → 电路图 JSON）、`App.js`（DOM / JointJS / 交互）
- 清掉未引用的冗余依赖：`w3.css`、`bootstrap.min.css`、`select2.*`、重复的 `joint.min.js`，页面体积从 4.2MB 降到 1.3MB
- JointJS 改用官方压缩版 `joint.min.js`（428KB），比原来的未压缩 `joint.js`（1.1MB）小 65%
- 去掉随包携带的 1.6MB 中文标题字体，改用系统 CJK 字体栈（`--var-font`）
- 前端依赖按固定版本拉取、不进源码仓库，由 CI 在部署前拉取并固化回仓库
- 加了一套零依赖的 Node 回归测试（见下）
- 加了 GitHub Actions 自动部署到 GitHub Pages

## 修复的问题

改造过程中发现并修掉了原版的这些问题：

1. **改名会破坏节点类型**
   原版用 `label.text` 存元件类型，同时又把「元素名称」编辑框的内容写回 `label.text`，
   于是把元件改名后执行「图形转文本」，导出的 `type` 就变成了用户输入的名称，图模型随即损坏。
   现在把连线类型单独存在模型属性 `kind` 上，改名只动显示文本。

2. **纯数字变量名与自动编号撞 key**
   变量名如果叫 `3`、`4`，生成的 `Import` 节点 key 会和选择器的自动编号（3、4…）重复，
   `graph.getCell('3')` 只能拿到其中一个，电路静默画错。
   现在纯数字变量名统一加 `v` 前缀，连线引用同步改写。
   （原版对 `3 4 .` 会输出重复 key，测试里有对照断言。）

3. **项多于一个时把操作数当结果返回**
   原版对 `a b`、`a b . c` 这类输入会直接 `return e.pop()`，
   把最后一个变量名当成结果返回，界面于是把 `b` 当成错误信息显示出来。
   现在会明确报「缺少运算符：有 N 个项没有被合并」。

4. **加载时报 JSON 格式错误**
   原版 `<textarea>` 里的默认内容 `{nodeArray: [], linkArray: []}` 不是合法 JSON
   （键没加引号），所以每次打开页面状态栏都会显示 `JSON format Error, Use Empty Format.`。

5. **单个变量无法出图**
   原版 `LogicParser('a')` 返回字符串 `'a'`，上层把它当成错误信息，于是单个变量画不出电路。
   现在单个变量和常量都能正常生成。

6. **`[hidden]` 被 `display` 覆盖**
   改造中新加的 `.canvas__empty { display: grid }` 会盖掉浏览器默认的 `[hidden] { display: none }`，
   导致有电路时空状态提示还浮在画布上。已加全局 `[hidden] { display: none !important }`。

7. **元件图标画到了节点外面**
   图标没有设 `refX/refY`，`x/y` 被当成绝对坐标，图标实际画在节点左上角外侧。

8. **选择器端口标签没有文字**
   原版用 `attrs.portLabel.text` 给端口标注，必须用这个结构；写错的端口标签会渲染成空白。

9. **删除死代码**
   `updateGraph()` 引用了未定义的 `ELCreate` 和 `chosedElement.Sheets`；
   `UpdateOption()` 引用了不存在的 `#sheet3`（select2 也随之成了死依赖）。这些都已移除。
   另外把 `for (x of ...)` 造成的隐式全局变量改成了局部变量。

## 项目结构

```text
.
├── public/                  # 站点根目录（部署的就是它）
│   ├── index.html           # 页面骨架
│   ├── style.css            # 设计令牌 + 双主题 + 布局

│   ├── App.js               # 画布、交互、真值表、导出、持久化
│   ├── latch.json           # 手写图模型示例（选择器搭的锁存器）
│   ├── assets/              # 元件图标（含 favicon.svg）
│   └── lib/                 # 前端依赖，由 scripts/vendor-deps.sh 生成，不进 git
├── scripts/
│   └── vendor-deps.sh       # 按固定版本拉取 public/lib
├── tests/
│   ├── engine.test.js       # 回归测试（零依赖）
│   └── fixtures.json        # 由原版程序生成的基准夹具
├── .github/workflows/pages.yml
└── README.md
```

运行时依赖的版本与来源见[前端依赖](#前端依赖)。
